# AttendAI Data Dictionary

The AttendAI backend utilizes MongoDB as its NoSQL database, structured around five primary Mongoose schemas: `User`, `Department`, `Subject`, `Class`, and `Attendance`.

---

## 1. User
Represents all actors in the system: Admins, Faculty, and Students.

| Field | Type | Properties | Description |
| :--- | :--- | :--- | :--- |
| `_id` | ObjectId | Primary Key | Unique identifier generated by MongoDB. |
| `name` | String | Required | Full name of the user. |
| `email` | String | Required, Unique | Username or email address used for login. |
| `password` | String | Required, Hidden | bcrypt-hashed password. Minimum 6 characters. |
| `role` | String | Enum | Role-based access control. Options: `student`, `faculty`, `admin`. Default: `student`. |
| `idNumber` | String | Unique, Sparse | Enrollment number for students or Employee ID for faculty. |
| `department` | ObjectId | Ref: `Department` | The department the user belongs to. |
| `course` | String | Optional | Academic course (e.g., BTech) for students. |
| `year` | String | Optional | Academic year (e.g., TY, SY) for students. |
| `faceEmbeddings` | Array[Number] | Default: `[]` | 128-dimensional float array representing the user's face biometric data for AI validation. |
| `createdAt` | Date | Auto | Timestamp of document creation. |
| `updatedAt` | Date | Auto | Timestamp of last document modification. |

---

## 2. Department
Represents an academic department within the institution.

| Field | Type | Properties | Description |
| :--- | :--- | :--- | :--- |
| `_id` | ObjectId | Primary Key | Unique identifier. |
| `name` | String | Required, Unique | Full name of the department (e.g., "Computer Science"). |
| `code` | String | Required, Unique | Shortened department code (e.g., "CS"). Stored in uppercase. |
| `description` | String | Max 500 chars | Optional detailed description of the department. |
| `createdAt` | Date | Auto | Timestamp of document creation. |
| `updatedAt` | Date | Auto | Timestamp of last document modification. |

---

## 3. Subject
Represents a specific subject or course module.

| Field | Type | Properties | Description |
| :--- | :--- | :--- | :--- |
| `_id` | ObjectId | Primary Key | Unique identifier. |
| `name` | String | Required | Full name of the subject (e.g., "Data Structures"). |
| `code` | String | Required, Unique | Subject code (e.g., "CS201"). Stored in uppercase. |
| `department` | ObjectId | Ref: `Department` | The department that owns or teaches this subject. |
| `credits` | Number | Required, Default: 3 | Academic credits assigned to the subject. |
| `createdAt` | Date | Auto | Timestamp of document creation. |
| `updatedAt` | Date | Auto | Timestamp of last document modification. |

---

## 4. Class
Represents a physical or virtual classroom session, bundling the subject, faculty, students, and a weekly schedule.

| Field | Type | Properties | Description |
| :--- | :--- | :--- | :--- |
| `_id` | ObjectId | Primary Key | Unique identifier. |
| `name` | String | Required | Name of the division or class (e.g., "TY-BTech-A"). |
| `subject` | ObjectId | Ref: `Subject`, Req | The subject being taught. |
| `faculty` | ObjectId | Ref: `User`, Req | The faculty member responsible for the class. |
| `students` | Array[ObjectId] | Ref: `User` | Array of students enrolled in this specific class block. |
| `schedule` | Array[Object] | Sub-document | Array representing the weekly timetable slots for this class. |
| `schedule[].dayOfWeek` | String | Enum, Required | Day of the week (`Monday`, `Tuesday`, etc.). |
| `schedule[].startTime`| String | Required | Start time in `HH:MM` format. |
| `schedule[].endTime` | String | Required | End time in `HH:MM` format. |
| `schedule[].room` | String | Optional | Physical room number or location. |
| `schedule[].type` | String | Default: `Lecture`| Type of class session (e.g., `Lecture`, `Lab`, `Tutorial`). |
| `createdAt` | Date | Auto | Timestamp of document creation. |
| `updatedAt` | Date | Auto | Timestamp of last document modification. |

---

## 5. Attendance
Represents a single attendance marking session initiated by a faculty member.

| Field | Type | Properties | Description |
| :--- | :--- | :--- | :--- |
| `_id` | ObjectId | Primary Key | Unique identifier. |
| `class` | ObjectId | Ref: `Class`, Req | The class for which attendance is being marked. |
| `faculty` | ObjectId | Ref: `User`, Req | The faculty member who initiated the session. |
| `date` | Date | Req, Default: `now` | The date and time the session was created. |
| `sessionToken` | String | Required | Unique token generated when the session starts to prevent spoofing. |
| `attendanceCode`| String | Required | 4-digit numeric pin code shown on the faculty screen for verification. |
| `location.lat` | Number | Required | Latitude coordinate of the faculty device initiating the session. |
| `location.lng` | Number | Required | Longitude coordinate of the faculty device. |
| `radius` | Number | Req, Default: `100` | Acceptable radius in meters for students to be marked present. |
| `records` | Array[Object] | Sub-document | Array containing the actual student attendance data. |
| `records[].student`| ObjectId | Ref: `User`, Req | The student being tracked. |
| `records[].status` | String | Enum | `Present`, `Absent`, `Late`, `Excused`. Default: `Absent`. |
| `records[].markedAt`| Date | Optional | Exact timestamp when the student successfully verified identity. |
| `createdAt` | Date | Auto | Timestamp of document creation. |
| `updatedAt` | Date | Auto | Timestamp of last document modification. |
